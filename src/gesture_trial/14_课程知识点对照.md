## 4. 四个「高价值发现」

### 4.1 按课程的公式 P = W/e，你需要 1,409 万张图，但你只有 782 张

**课程原话（W5-ANN3 第 8 页）**：
> *"More complex answer, there has been shown to be a relationship between the number of patterns for training (P),
> the number of weights in the network (W) and the accuracy of the network (e). [Baum and Haussler, 1989]*
> **P = W/e**
> *EG. An ANN trained to 90% accuracy (e=0.1), with 50 weights (W) would need: 50 / 0.1 = 500 training patterns."*

**代入本 demo**：

| 项 | 值 |
|---|---|
| W（权重数） | 215,539 |
| 验证准确率 | 98.47% → e = 0.0153 |
| **P = W/e** | **215,539 ÷ 0.0153 ≈ 14,087,516 张** |
| 实际训练图数 | **782 张** |
| **差距** | **约 18,000 倍** |

**为什么还能做到 98.47%？** —— 这正是可以写进报告、也可以问 Yu Zhou 的问题。
可能的原因（**推测**，未验证）：
1. **权重共享**：一个 3×3 卷积核只有 9 个权重，却在 4096 个位置上复用 → 有效独立参数量远小于 215,539。
2. **输入高度冗余**：手势图是低维流形上的样本，不是任意 4096 维向量。
3. **Baum-Haussler 的前提是全连接网络**，对 CNN 未必直接适用。

> ⚠️ 这条公式的适用条件是**推测/需查证**；但"课程给了这条公式、而我的实测远超它"这个张力本身，就是一个好问题。

### 4.2 「最高值节点视为激发」= argmax = 你「无手势」bug 的理论源头

**课程原话（W5-ANN3 第 5 页）**：
> *"In ANNs with multiple output nodes, it is often the case that **the highest value node is considered to have fired**
> and the others not (**within threshold bounds**)."*

**这三层意思值得拆开**：
1. 课程教的分类规则**就是**"取最高的那个" → 代码里的 `np.argmax(probs)`。
2. 这个规则**天然没有"都不是"这个出口** → 所以框里放个深色方块，模型**必须**从 fist/palm/scissors 里挑一个。
3. 括号里的 **`within threshold bounds`** 是讲义留给阈值的口子 → 你可以正当地说：
   **"我在课程这一句的 threshold 上做了扩展，加了拒识（rejection）。"**

**实测证据**（本模型）：

| 输入 | fist | palm | scissors | 判为 |
|---|---|---|---|---|
| 深色方块（浅底） | **1.000** | 0.000 | 0.000 | fist |
| 深色圆（浅底） | **1.000** | 0.000 | 0.000 | fist |
| 纯黑 | **1.000** | 0.000 | 0.000 | fist |
| 随机噪声 | 0.031 | 0.000 | **0.969** | scissors |

→ 探针平均最高置信度 **0.898 > 0.8**，`看网络内部.py` 报**警告**。

### 4.3 ROI + 均值 + 标准差 = ER3008 W2 的原话

**课程原话（W2 Image Analysis）**：知识点里明列
- *感兴趣区域 (region of interest)*
- *灰度分布 (Grey-level distribution)*
- *均值 (mean) 与标准差 (standard deviation)*

- MATLAB 函数：`mean2(A)`、`std2(A)`、`imhist(A, n)`

**你的代码里**（[`01_capture.py`](01_capture.py)）：ROI 裁剪 + `roi.mean()` + `roi.std()` + `roi_std < 20.0` 判空。

→ **这就是 ER3008 W2 的内容，逐字对应，而你本周刚上过这一讲。**

### 4.4 一个可以拿去问老师的技术细节：ReLU 不满足讲义的判据

**课程原话（W4-ANN2）**：隐藏层激活函数的要求是
- *连续 (Continuous)*
- *可微 (Differentiable，尽量简单)*
- ***函数应饱和 (Function should saturate)***
- *非线性 (non-linear)*

**你做的是**：`activation="relu"` → 满足连续、可微、非线性，**但正半轴不饱和**（线性增长，无上界）。

→ 现代实践用 ReLU，而讲义的判据是围绕 sigmoid 系写的。**这是一个诚实、具体、可讨论的问题**，
比问"什么是反向传播"高一个层次。
