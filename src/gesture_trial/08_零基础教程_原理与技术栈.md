## 一、先看全局：这个 demo 在做什么

一句话：**让电脑看一眼摄像头画面里手的形状，说出这是"握拳 / 手掌 / 剪刀手"中的哪一个。**

拆开是四步：

```
① 拍照        摄像头每秒拍很多张，每次取一张
② 裁剪缩小    只留中间方框 → 缩成 64×64 → 转灰度（去掉颜色）
③ 提取特征    「这块像不像一条斜边？」「这块像不像指缝？」
④ 打分        三个类别各算一个分数 → 分最高的胜出
```

**②③④ 合起来就是"神经网络"。** 它不是黑箱，而是**一个带很多旋钮的函数**：

> 你喂进去 64×64 = 4096 个数字，它吐出 3 个概率。
> 那些"旋钮"是 **215,539 个小数**。**训练就是把它们拧到合适的位置。**

打个比方：**调收音机。** 很多旋钮要拧，目标是声音最清楚。区别是你不知道每个旋钮管什么，
所以只能"听一下 → 微调 → 再听一下"。训练就是这么回事，只不过"听"换成了"算误差"。

## 二、原理：四个关键部件

### 2.1 卷积（Convolution）—— 拿放大镜一格一格地扫

不要一次看整张图，而是**拿一个 3×3 的小窗口，从左上角开始一格一格滑过去**。每滑到一个位置问一句：

> "这一小块里，有没有我关心的图案？"

**"我关心的图案"本身也是学出来的**（它就是旋钮）。数学上这一步就是：
把窗口里的 9 个数字和 9 个旋钮分别相乘，再全部加起来，得到一个分数。

- 分数高 = 这一小块很像那个图案
- 滑完整张图 = 得到一张"哪里像"的地图，叫**特征图**

我们这个网络有三层卷积，分工是**逐级抽象**：

| 层 | 学到的东西 |
|---|---|
| 第 1 层 | 边缘、明暗交界 —— 最基础的笔画 |
| 第 2 层 | 把边缘组合起来 —— 指缝、指尖的尖角 |
| 第 3 层 | 更整体的形状 —— "五指张开" vs "握成一团" |

> **为什么不能只堆全连接层**：全连接层把每个像素和每个神经元都连起来，
> 等于让网络自己从零去发现"相邻像素是有关的"。而卷积**天生把"只看附近"这条先验写进去了**，
> 所以学得快得多，参数也少得多。

### 2.2 池化（Pooling）—— 把照片打成马赛克

每 2×2 个数字里只留最大的那个，图就缩小一半。

**它解决一个很实际的问题**：你的手不可能每次都停在同一个像素位置。
池化之后，手往右挪几个像素，"最大值"还是那一个 —— **答案不变**。

一句话：**池化买来的是"位置上的宽容"。**

### 2.3 全连接 + Softmax —— 最后的投票

三层卷积之后，网络手里有一堆"像 / 不像"的分数。全连接层把它们汇总，
对三个类别各给一个**原始分数**（比如 `2.1, -0.4, 0.7`）。这些分数不好解释，
所以最后用 **Softmax** 把它们变成**加起来等于 1 的概率**：

- 分数越高 → 概率越接近 1
- 三个概率必定加起来是 1（这就是"概率分布"）

你在屏幕上看到的那三根条，就是这三个数。

### 2.4 ReLU —— 给网络"非线性"

`ReLU(x) = max(0, x)`：负数变 0，正数照抄。看起来蠢，但没有它不行。

**为什么必须有**：如果每一层都只是"乘一乘、加一加"（线性运算），
那**一百层叠起来在数学上等价于只有一层** —— 网络再深也没用。
插入 ReLU 之后，层数才真正变成"能力"。

## 三、训练：网络是怎么"学会"的

### 3.1 三步循环，重复很多遍（每一遍叫一个 epoch）

```
① 前向：把一批图片喂进去，拿到预测概率
② 算损失：拿预测和正确答案比，算出一个「有多错」的数字（交叉熵）
③ 反向：算出「每个旋钮往哪边拧会让损失变小」（梯度），朝反方向拧一小步
```

第 ③ 步就是**反向传播（backpropagation）**：用链式法则从最后一层往前，
一次高效算出全部 215,539 个梯度。每一步挪多远叫**学习率**。

> 📌 **这部分你在 EL3300 已经学过**：
> `Week 3-ANN1`（感知机 / Hebb 网 / 学习率 / epoch）、
> `Week 4-ANN2`（MLP + 反向传播逐步算法 + 激活函数 + 梯度下降 + 隐藏层）、
> `Week 5-ANN3`。
> 本文只是把同一套东西**换到图像上**。**去翻你自己的讲义，比看本文更权威。**

### 3.2 为什么必须留一部分数据"不看"

我们把 1008 张图分成 **806 张训练 / 202 张验证**。**验证集在训练时完全不参与拧旋钮。**

为什么？因为网络完全有能力**背下训练集**（记住每张图的像素），那样训练分数会很高，
但它什么也没学会。验证集就是那块**没背过的考题**。

> 一句话：**训练集是课本，验证集是模拟考。用课本的分数判断水平，等于自己考自己。**

### 3.3 防止"背题"的三个手段

- **数据增强**：训练时把图片随机旋转、缩放、平移一点。
  等于凭空造出更多变化，逼它学**形状**而不是**像素位置**。
- **Dropout**：训练时随机"关掉"一部分神经元，不让某几个神经元垄断判断。
- **EarlyStopping**：验证分数连续 8 轮不再变好就停下，并回滚到最好的那一轮。
  （你这次真实训练**在第 13 轮触发了早停** —— 见 `reports/metrics.txt`。）

## 四、技术栈选型：为什么是这三样

```
      ┌──────────────┐
      │    Python    │  把三件事串起来的"胶水"：流程控制、文件、调用下面两个库
      └──────┬───────┘
             │
   ┌─────────┴─────────┐
   ▼                   ▼
┌────────────┐   ┌────────────────────┐
│   OpenCV   │   │  TensorFlow / Keras │
│ 取图 / 裁剪│   │  建网络 / 训练 /     │
│ 缩放 / 灰度│   │  评估 / 导出 TFLite  │
│ (I/O 与    │   │  (学习与推理部分)    │
│  预处理)   │   │                     │
└────────────┘   └────────────────────┘
```

| 部件 | 负责什么 | 为什么是它 |
|---|---|---|
| **Python** | 调度、文件读写、把两个库连起来 | 三个库都是一等公民；而且**你 EL3300 的主力学就是 Python**，不额外增加语言负担 |
| **OpenCV** | 打开摄像头、镜像、裁 ROI、缩到 64×64、转灰度 | 工业标准，摄像头与图像 I/O 最省事 |
| **TensorFlow + Keras** | 定义网络、训练、算指标、导出 TFLite | Keras 的 API 足够短；**TFLite 是它最硬的差异化优势**，见 4.2 |

### 4.1 为什么**不用传统 CV 方法**（肤色分割 + 轮廓 + 凸缺陷）

传统做法大概是：找出肤色区域 → 求手的轮廓 → 数**凸缺陷**（手指之间的"V"形凹口）来判断张开了几根手指。

**它的优点**：不需要数据、不需要训练、规则可读、速度快。

**为什么这里不用**：

1. **肤色不是可靠特征。** 不同人、不同光照、不同摄像头的白平衡，肤色 RGB 值差得很远。
   要让它稳，最后往往得手工堆一堆阈值 —— 而阈值是**换个房间就废**的东西。
2. **"数凸缺陷"对姿态极敏感。** 手一转、侧一点、握拳时轮廓一糊，凸缺陷就数不对了。
3. **最关键的一条**：传统方法里的每条规则，都是**你替机器想好的**。
   神经网络把"该看什么"这件事**也交给数据去决定** —— 这正是深度学习相对传统 CV 的核心差别。

> 📌 **这段你手上有现成对照物。**
> ER3008 的 Hough 变换实验（`_课程材料/ER3008/_文本提取/Hough_Transform_lab.txt`：
> 直方图均衡 → Canny 边缘 → `hough` 累加器 → `houghpeaks` → `houghlines`）
> 和 `vision.CascadeObjectDetector` 那个人脸检测脚本，走的都是传统路线：
> **手写特征（边缘 / 梯度）+ 分类器**。
> 你已经亲眼见过这条路怎么搭 —— 所以"为什么还要学神经网络"对你就有了具体答案，而不是空话。

**但必须说清**：传统方法不是"落后"。在数据少、算力紧、需要可解释性的场合，
它常常才是正确选择。**正确说法是"选型取决于约束"，不是"神经网络更好"。**

### 4.2 为什么**不用 PyTorch**

很直白：**PyTorch 也能做，但在这个项目上它没有优势，还有两个实际损失。**

1. **导出到单片机的链路。** 这个项目的落点是 STM32（**1 MB Flash / 128 KB RAM**）。
   TensorFlow 系的 **TFLite + int8 量化 + CMSIS-NN** 是嵌入式端最成熟的现成路径；
   PyTorch 要走到同一目标得多绕一步（ONNX 之类），对一个本科毕设是纯增风险。
2. **学习成本。** 两边 API 都能学会，但既然目标端是 TFLite，**用同一套工具链从头走到尾**更省事。

**什么时候该选 PyTorch**：做研究、要改网络内部结构、要跟最新论文实现对齐时。那是另一个场景。

### 4.3 为什么**不用 MediaPipe 这类现成方案**

MediaPipe Hands 能直接吐出 21 个手部关键点，效果远好于我这个 64×64 小网络。

**但用了它，这个项目就没了**：

- 我的目的是**理解并走通"从数据到部署"的全流程**，不是拿一个能用的手势识别器。
- MediaPipe 是个预训练黑箱。用了它，我学到的是"怎么调它的 API"，
  而不是"卷积在干什么、验证集为什么必须留、量化为什么能省四倍空间"。
- 更实际地说：**毕设要展示的是我的判断力和动手链条，不是调库速度。**

> 一句话：**能用现成方案 ≠ 应该用现成方案。** 取决于目标是"交付功能"还是"建立能力"。

### 4.4 为什么**不用 MATLAB**（虽然我本机有 Deep Learning Toolbox）

我本机 MATLAB R2026a 确实装了 Deep Learning Toolbox，理论上能训。**实际卡在两处**：

1. **打不开摄像头。** MATLAB 的 `webcam` / `preview` / `snapshot` 需要 Image Acquisition
   Toolbox 的**硬件支持包**，我这边装了 **0 个** —— 所以摄像头这条路根本走不通。
2. **部署端不匹配。** 目标是把模型搬到 Cortex-M，TFLite / CMSIS-NN 这条链在 Python 侧更顺。

MATLAB 仍然是我做 ER3008 图像实验的主力（`imread` / `histeq` / `edge` / `hough` 那一套，
本机 R2026a 上实跑过）。**工具没有高下，只有合不合适。**

## 五、【核心案例】验证集 99%，现场全错 —— 数据里藏了一条捷径

这是这次**真实发生**的事，也是整份教程里最值得记住的一节。

### 5.1 发生了什么

- 采了 1008 张图（fist 419 / palm 289 / scissors 300）
- 训练完，**验证集准确率 99.01%**
- 打开实时演示 —— **基本认不出来**

### 5.2 查出来的原因

我去看了那 1008 张图的**实际数值**：

| 类别 | 张数 | 框内平均亮度 | 对比度 std |
|---|---|---|---|
| fist | 419 | 139.0 | 54.1 |
| palm | 289 | 169.2 | 36.0 |
| scissors | 300 | **237.3** | **17.3** |

- scissors 的 std 只有 17 → 那 300 张**几乎就是一张白墙**
- 看图更直接：**握拳和剪刀手的手都举在了框外**，框里装的是脸、头发、白墙

**★ 根因（2026-10月8日 补充）：Windows 工作室效果的「自动取景」**

第一次采集时开着 **Windows Studio Effects 的自动取景**，摄像头**一直跟着脸自动变焦**。
自动取景要把脸保持在画面中心 —— 于是中间那个 ROI 框里装的**永远是脸**，
手放到哪儿都进不去。这就是"框里是脸和头发"的来源。

> ⚠️ **这是一条比任何算法知识都重要的教训：**
> **数据坏了，改网络结构救不回来。**
> 而这次数据坏掉的原因甚至不在代码里 —— 在一个操作系统的摄像头开关里。
> **做机器学习，第一步永远是确认你喂进去的到底是什么。**

**结论：网络学的是"框里有多亮"，不是"手的形状"。**

- 框暗 → 拳
- 框中 → 掌
- 框**很亮** → 剪刀

这在机器学习里叫 **捷径学习（shortcut learning）**：

> 当数据里存在一条**和标签相关、但和真实任务无关**的线索（这里是背景明暗），
> 网络会优先抓它 —— 因为它**比学手势形状容易得多**。

### 5.3 为什么验证集也有 99%？（这是最关键的一问）

因为**验证集和训练集出自同一次采集、同一机位、同一光照**。
那条捷径在验证集上**同样成立**。

> **所以：验证集只能告诉你"在和数据同分布的新样本上表现如何"。
> 它无法保护你免受"数据本身有偏"这个错误。**

### 5.4 三件该记住的事

1. **验证集准确率高 ≠ 能用。** 那次 99% 是"自己考自己"考出来的。
2. **数据质量 > 模型调参。** 这次的错，改网络结构救不回来，只能重新采数据。
3. **要主动检查数据，而不是只看损失曲线。** 后来我在采集脚本里加了实时提示：
   框内 `std < 20` 就变橙色警告 —— 这个失败**本该在采集现场就被拦住**。

### 5.5 正确的做法（已写进 `07` 第 5 节）

1. **手必须在框里** —— 判断标准是右下角小图，不是你的感觉
2. **三类交错采**（fist 60 → palm 60 → scissors 60，轮回 3~4 轮）
   —— 如果机位或光照在采集时漂移了，一类一类采会让**漂移和类别绑定**，网络学到的就是漂移
3. **每一类都要经历同样的变化**（距离、位置、开灯关灯），而不是"某一类专门采暗的"
4. 采完做**数据健康检查**，全绿才训练

## 六、速查表：10 个概念 + 明天能说出口的一句话

| # | 概念 | 一句话 | 英文（明天可直接说） |
|---|---|---|---|
| 1 | 神经网络 | 一个有很多参数、用数据把参数调好的函数 | A network is a parameterised function; training adjusts the parameters to match the labels. |
| 2 | 参数 | 215,539 个小旋钮 | About two hundred thousand parameters get adjusted during training. |
| 3 | 卷积 | 拿小窗口扫全图，问"这里像不像某个图案" | Convolution learns local templates — edges first, then combinations. |
| 4 | 池化 | 缩小图片，让位置稍微变一点不影响答案 | Pooling shrinks the feature map so small shifts do not change the answer. |
| 5 | ReLU | 把负数变 0，给网络非线性 | Without a non-linear activation, stacking layers collapses into one linear function. |
| 6 | Softmax | 把分数变成加起来等于 1 的概率 | Softmax turns raw scores into probabilities that sum to one. |
| 7 | 损失 | "有多错"的量化指标，训练就是让它变小 | The loss is the number we minimise; cross-entropy punishes confident mistakes hardest. |
| 8 | 反向传播 | 用链式法则算出每个旋钮该往哪拧 | Backpropagation computes the gradient w.r.t. every parameter via the chain rule. |
| 9 | 验证集 | 训练时完全不看的"模拟考" | The validation set is never used for training — it is the only honest estimate on unseen data. |
| 10 | 量化 | float32 → int8，体积缩到约 1/4 | Quantisation maps float weights to 8-bit integers: roughly 4× smaller, no accuracy loss. |

## 七、如果你只记三句话

1. **神经网络 = 带很多旋钮的函数；训练 = 用数据把旋钮拧对。**
2. **卷积看局部、池化要宽容、Softmax 做投票 —— 三个部件各解决一个具体问题。**
3. **验证集高分不等于能用。** 数据里有偏，模型就会走捷径 —— 这是这次真实翻车的教训。
