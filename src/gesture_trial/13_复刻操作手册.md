## 4. 第 3 步：自己写 5 个 `.cmd`（10 分钟）★ 重点

### 4.1 为什么是 `.cmd` 而不是复制粘贴命令

**因为你上次粘贴出事了。** 你贴进来的一整块里混着控制台横幅、`PS C:\Users\<you>>` 提示符和历史输出，
PowerShell **会逐行执行**，于是满屏 `The term '...' is not recognized`，真正的命令一条都没跑。
更糟的是：`PS` 恰好是 `Get-Process` 的别名，于是又打出一堆进程列表。

**`.cmd` 双击就跑，不会混进任何东西。** 这也是你上一轮明确要的形式。

### 4.2 五个 `.cmd` 的完整内容

**怎么创建**：在 `<复刻目录>` 里右键 → 新建 → 文本文件 → 把下面内容粘进去 → 存盘 →
把文件名改成 `训练.cmd`（**注意：要先把"显示文件扩展名"打开**，否则会变成 `训练.cmd.txt`）。

> 📌 **编码要求**：存成 **UTF-8 无 BOM**。用 VS Code 存的时候看右下角，
> 点它 → "Save with Encoding" → 选 `UTF-8`（不是 `UTF-8 with BOM`）。
> 有 BOM 的话 `chcp 65001` 会把 BOM 当命令执行，报一句莫名其妙的错。

**通用开头**（下面 5 个文件都是这个开头，我先解释一遍，后面就不重复了）：

```bat
@echo off
chcp 65001 >nul
cd /d "%~dp0"
set PY="C:\Users\<you>\venvs\mp3000-nn\Scripts\python.exe"
```

| 行 | 在干什么 |
|---|---|
| `@echo off` | 不把每条命令本身打印出来（否则屏幕全是命令原文，看不到结果） |
| `chcp 65001 >nul` | 把控制台编码切成 UTF-8，否则中文输出是乱码。`>nul` = 把这行自己的输出丢掉 |
| `cd /d "%~dp0"` | **最关键的一行。** `%~dp0` = 这个 `.cmd` 文件**自己所在的目录**（含末尾反斜杠）。<br>所以不管你是双击还是从别处调用，工作目录永远是脚本所在目录 → Python 才能找对 `data/`、`models/` |
| `set PY="..."` | 把 Python 全路径存进变量 `PY`。后面写 `%PY%` 就能用。<br>**为什么要全路径？** 因为裸 `python` 指到哪个版本不确定，而裸 `py` 是 3.14（装不了 TF） |

## 5. 第 4 步：采集数据（6 分钟）

### 5.1 ⚠️ 采集前必做：关掉 Windows 工作室效果

**这是 2026-10-07 那次失败的真根因**，不关掉你**一定会再失败一次**：

> Windows Studio Effects 的**自动取景**会跟着你的脸自动变焦，把脸固定在画面中心 ——
> 于是中间那个采集方框里装的**永远是脸**，手举到哪儿都进不去。

**关掉**（[微软官方文档](https://learn.microsoft.com/en-us/training/modules/windows-studio-effects/3-how-to-use)）：

| 办法 | 步骤 |
|---|---|
| **最快** | 任务栏右下角点 **网络 / 音量 / 电池** 图标 → 点 **Studio Effects** 磁贴 → 关 |
| **稳妥** | **设置 → 蓝牙和其他设备 → 摄像头 → 选你的前置摄像头 → 关闭 Studio Effects** |

**验证方法：头左右移动，画面不应该跟着变焦。**

> 找不到 Studio Effects 磁贴？官方说法是"设备可能没有受支持的 NPU"。
> 那说明自动取景来自**摄像头厂商自带的软件**，去"设置 → 应用"里找摄像头工具关掉。

### 5.2 采集操作

1. 双击 `重来_存档并采集.cmd`
2. 窗口里会打印一段 **Studio Effects 警告**（我新加的，每次启动都提醒你）
3. **按 `1` / `2` / `3` 切换类别**，屏幕左上角会显示当前类别和已存张数
4. **按住 `空格` 连续录制**（每 0.08 秒存一张），每个类别录 **6～7 秒**
5. 录完按 `q` 退出

**录制时的三个要点**：

| 要点 | 原因 |
|---|---|
| **手要完全放进中间的方框里** | 框外的内容会被裁掉，模型只看框内 |
| **三个类别用同一套背景、同一光照、同一个坐姿** | 保证类别之间**只有手势不同** —— 否则模型会去学背景（这就是捷径学习） |
| **每个类别录的量要差不多** | 数量悬殊会让模型偏向样本多的那类 |

### 5.3 怎么读屏幕上的健康度读数

画面**右上角**有一行 `box mean=... std=...`：

| 读数 | 含义 | 该怎么做 |
|---|---|---|
| `std` **低于 20** | 框里几乎是纯色 → **手不在框里** | 框会变橙色并弹 `! BOX LOOKS EMPTY`，把手放进去 |
| `mean` 三个类别差很多 | 三类背景亮度差太多 → **捷径学习的温床** | 调光照，让三类亮度接近 |

> **`std` = 对比度。** 框里全是手（有手指、有阴影）时对比度高；
> 框里是白墙或纯黑时对比度接近 0。**这是你当场就能发现的"数据坏了"信号。**

退出时会自动跑一次 `sanity_report()`（数据健康检查）。**别跳过它** —— 它会检查每个类别的 `std` 和类别间亮度差，有问题直接告诉你。
