# 垃圾分类演示 · 操作手册

> 面向：Lowlife（不需要懂命令行）
> 机器：树莓派 4B · `192.168.1.66` · 演示页端口 **8090**
> 写于 2026-10-18（周日）

---

## 一、一句话说明

**树莓派上已经跑着一个网页，它会把 36 张真实垃圾照片循环送进模型识别，并把"预测 / 置信度 / 真实类别 / 耗时"直接画在图片上。**

**你只需要打开一个网址，什么都不用启动。**

```
http://192.168.1.66:8090/
```

## 二、三种打开方式（从最省事到兜底）

### ① 直接在自己笔记本浏览器里打开 ← **推荐，最省事**

在 Windows 的 Chrome / Edge 地址栏输入：

```
http://192.168.1.66:8090/
```

**✅ 不用装任何东西。** 树莓派开机就自动跑这个服务，重启也不用手动启动。

1. 先打开树莓派桌面：`http://192.168.1.66:6080/vnc.html`

> 图标背后做的事：确认服务在跑 → 用 Chromium 以"应用模式"打开页面。
> 找不到图标时：点左下角菜单 → 搜「垃圾分类」也能进去（我在应用菜单里也放了一份）。

## 三、页面上每个东西是什么

```
┌─────────────────────────────┬──────────────────┐
│                             │  当前判定          │
│        垃圾照片              │   金属            │
│   （下方有绿/红结果条）        │   置信度 98.4%    │
│                             │   真实类别：金属    │
│                             ├──────────────────┤
│                             │  Top-3 概率       │
│                             │   金属   98.4% ███│
│                             │   塑料    1.2%     │
│                             ├──────────────────┤
│                             │  累计（本次运行）   │
│                             │   已识别   15      │
│                             │   判对     12      │
│                             │   准确率   80.0%   │
│                             ├──────────────────┤
│                             │  操作             │
│                             │  [图片循环][暂停]  │
│                             │  [摄像头][下一张]  │
└─────────────────────────────┴──────────────────┘
```

### 图片上的那条横条

| 颜色 | 含义 |
|---|---|
| **绿色** | 判对了（预测 = 真实类别）|
| **红色** | 判错了 —— **这是要留着的，不要藏** |

条上的字：

| 字段 | 含义 |
|---|---|
| `PREDICT: METAL 98.4%` | 模型说的是"金属"，把握 98.4% |
| `truth: metal` | 这张图的**真实类别**（来自数据集标注）|
| `28.9 ms on Raspberry Pi 4B` | **在树莓派上跑一次推理的耗时** |
| `12/15 80.0%`（右上） | 本次运行累计判对 / 总张数 / 准确率 |
| `#15/36 [IMAGES]`（右下） | 第几张 / 共几张 / 当前模式 |

### 四个按钮

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| **图片循环** | 每 2 秒换一张，自动识别 | 常态演示 |
| **暂停** | 冻结在当前这张 | **讲解某一张判错的时候按它** |
| **摄像头** | 切到实时摄像头 | **摄像头到货后才能用**；没到会提示"未连接"并自动退回图片模式，不会崩 |
| **下一张 →** | 立刻换下一张 | 讲到一半想跳过时 |

## 四、演示时怎么讲（照着说就行）

**开场（30 秒）：**

> 这条链路的输入是 36 张**真实生活垃圾照片**，来自公开数据集 TrashNet 的**验证集**——模型训练时没有见过这些图。
> 每一张都会在树莓派 4B 上**本地推理**，一次大约 29 毫秒。

**中段（指着屏幕说）：**

> 屏幕上这条就是模型输出：预测类别、置信度、以及真实类别。
> **绿色的表示判对，红色的表示判错** —— 我故意把判错的也留在里面，因为这才是真实成绩。

**如果被问"准确率多少"：**

> 这 36 张上的准确率会实时显示在右上角，大约在 **75%–85%** 之间浮动。
> 整个验证集 379 张的准确率是 **78.89%**（float32 版本是 81.53%，int8 量化后掉了 2.64 个百分点）。
> 模型只有 **2.62 MB**，压缩了 8 倍，就是为了能塞进树莓派。

**如果被问"它什么地方会错"：**

> 主要是**塑料和玻璃互相认错** —— 这两类都是半透明 + 有反光。同样的错在 PC 上也一样犯，说明**不是量化造成的**，是数据本身难。

## 五、把"自己家的垃圾"加进去

**目前这 36 张是数据集里的图。你完全可以换成自己拍的照片。**

### 做法（全程图形界面，不用命令行）

1. 用手机拍几张：矿泉水瓶、易拉罐、纸板箱、打印纸、玻璃罐
2. 传到电脑
3. 打开树莓派桌面：`http://192.168.1.66:6080/vnc.html`
4. 桌面双击**文件管理器**（`pcmanfm`）
5. 进去这个路径：

   ```
   /home/niyoujia/trashnet_demo/demo_images/
   ```

6. **按类别把照片拖进对应的文件夹**：

   | 文件夹 | 放什么 |
   |---|---|
   | `cardboard` | 纸板、纸箱 |
   | `glass` | 玻璃瓶、玻璃罐 |
   | `metal` | 易拉罐、铁罐 |
   | `paper` | 打印纸、报纸、纸袋 |
   | `plastic` | 塑料瓶、塑料袋 |
   | `trash` | 不属于上面的（陶瓷、复合材料）|

7. 拖完就生效 —— **页面会自动把新图片加进循环，不用重启。**

> ⚠️ **照片要放在"它真正的类别"文件夹里**，否则页面上的 "truth" 就是错的，演示就失去意义了。
> ⚠️ 文件名随意，但只用 `.jpg / .jpeg / .png`。

## 六、出问题怎么办

| 现象 | 原因 | 你该做什么 |
|---|---|---|
| 浏览器打不开 `:8090` | 服务挂了 | 打开树莓派桌面 → 双击「垃圾分类演示」图标（它会自动重启服务）|
| 页面开着但图不动 | 网络断了一下 | 按 F5 刷新页面 |
| 一片 `NO RESULT` | 图库读不到 | 告诉我，我上去看 |
| 你连不上树莓派的**任何**地址 | 树莓派真的掉线了 | **拔电源等 10 秒再插**，等 2 分钟 |
| 页面提示"摄像头：未连接" | 摄像头还没到 | 正常，不用管 |

**⇒ 只要树莓派能开机，`:8090` 就会自己起来。服务设了 `Restart=always`，崩了 3 秒后自愈。**
